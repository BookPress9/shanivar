## Always true
> - Nothing is pushed, deployed, posted, sent, bought or published without the founder's explicit word for that specific action.
> - Shanivar Jira only (shanivar.atlassian.net, project DEV). Never RoboMQ.
> - Founder alone accepts stance changes (`SHANIVAR_STANCE.md:5`).
> - Read existing files first; cite file:line; never invent; write `UNRESOLVED:` instead of guessing.
> - No Device Admin or Accessibility Service; never claim "impossible to bypass".
> - No streaks, scores, ranks or gamification; no health or medical claims.
> - Unreviewed practices stay labelled DRAFT / internal test.
> - Practice and personal data stay on the device; no secrets in files or chat.
> - Temporary build flags (`ROUTINE_V3`) are never committed.
> - Marketing is paused until the founder unpauses it in a repo record.
