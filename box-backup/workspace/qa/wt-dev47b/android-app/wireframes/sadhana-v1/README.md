# Shanivar Sadhana — immersive interface study

Interactive founder-review prototype, 12 October 2026. Open [index.html](index.html) directly in a browser. The project is offline and buildless. It stores demo state in browser localStorage and uses only repository-reviewed foundation language plus clearly labelled design proposals.

## Experience thesis

The aura is not a badge layer. It comes from stillness, darkness, bronze light, deliberate motion and language with weight. The central interface is a Living Spine: an articulated divine spinal form, seven-centre subtle-body teaching map, and branching symbolic vagal layer with firefly-like pulses. The pulse responds to a user’s explicit self-check, never sensors or an inferred autonomic state. The trace reflects concrete practice activity; chakra illumination is selection and navigation, never diagnosis or a claim that energy was measured. Historical chakra systems vary, and the common contemporary map is not presented as anatomy.

The user’s aura grows through visible ownership: fewer prompts, chosen duration, clear decisions, factual active minutes and practice without the app. Missed days cause no visual damage. No XP, streak loss, rank, public comparison, spiritual title or readiness score exists.

The capability spine is `Arrive → Return → See → Choose → Carry`. These are verbs describing what a person may practise, not ranks describing who they are. Deep study is always open. Practice activity never unlocks intensive methods.

The spine now has 33 individually rendered practice segments grouped into cervical, thoracic, lumbar, sacral and coccygeal regions. A completed reviewed practice or an explicit independent-practice report advances the visual current by one segment. Early endings remain visible without completing a segment, and missed days cause no loss. Chakra thresholds reveal context; the animation is not evidence that kundalini or physiological energy moved.

## Voice

The final copy uses Shanivar’s direct pattern: state the current fact, name the choice, give one action, then return the person to ordinary life. The visual system may feel sacred; the words do not tell the practitioner that they are transformed, regulated, awakened or spiritually advanced. Examples: “Give this 3 honest minutes,” “What is true right now?”, “See the map. Test the practice,” and “You ended the practice.”
