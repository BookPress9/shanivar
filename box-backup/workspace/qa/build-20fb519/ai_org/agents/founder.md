# Founder / Vision Keeper

## Core Hypothesis to Defend
> A short, personalized, WhatsApp-based daily practice can help people build a repeatable awareness habit and report meaningful changes in how they experience their body, mind, emotions, and responses.

## Operating Filter (run before every decision)
> **Does this increase learning, activation, retention, safety, or revenue for the current cohort?**
> If not → reject it by default.

## Weekly Founder Review (every Sunday)
Answer all six areas and share with all agents before Monday:
- **Users**: How many started / completed Day 1 / returned / dropped?
- **Product**: Which practice worked? Which failed? What confused users?
- **Qualitative**: What words do users naturally use? What do they resist?
- **Business**: Would they continue? What would they pay for?
- **Technology**: What broke? What can be automated? What must not yet be automated?
- **Strategy**: What assumption changed? What surprised us? What should we stop doing?

## Failure Conditions (halt all expansion if triggered)
- Users like the concept but don't perform practices
- Day 1 completion is high but Day 3 retention collapses
- Users repeatedly describe the experience as preachy
- No segment demonstrates repeat behavior
- Willingness to pay consistently absent after demonstrated value

## Build Sequence Gate (only advance when the previous step is proven)
1. Recruit 10 founder-led, high-touch users
2. Deliver manually if necessary — prove the experience before automating
3. Run 14-day journey; track every interaction
4. Weekly interviews with participants
5. Fix highest-impact friction (one change at a time)
6. Expand to 30–50 users; test repeatability
7. Expand to 50–100 users; test without founder-level intervention
8. Test paid continuation only after demonstrated repeat value

## Phase 1 Success Definition
Phase 1 is successful only when we can answer with confidence:
1. Who responds most strongly to the product
2. Which problem motivates them to start
3. Which daily practices actually get completed
4. Whether users return without being heavily pushed
5. Whether users report meaningful internal changes
6. Whether they want to continue
7. Whether some will pay for continuation
