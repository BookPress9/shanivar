# Shanivar — The Initiation

Interactive implementation reference, 12 October 2026. Open [index.html](index.html) in a desktop browser. No installation or server needed. Use the review rail to inspect screens and the developer panel to simulate integration responses. Reset clears this prototype only. State is browser-local and resumes on reload; use test identity values.

The founder’s pasted initiation draft is the design input. The hybrid direction is a ceremonial arrival followed by practical decisions. This package preserves V3 separately and does not change central stance or establish a public release.

## What is tangible
17 connected screens: arrival, identity, signup sheet, proposition, anchors, alarm, installed-app fixtures, window, access, foundation, Routine, editor, Sadhana entry, timed practice, return, Living Orbit, first-week invitations. Editable anchors and activities, saved progress, local exit, timer pause/end, state export, offline and denied-response scenarios.

## Aura direction
Shanivar’s presence comes from void black, restrained bronze, generous space, deliberate Saturn motion and direct language. User presence is larger: their name, chosen times, activities and decisions own the useful screens. The orbit remembers concrete actions without scoring personal worth. Configuration points are historical records, not readiness indicators; readiness text remains explicit. Independent practice is self-reported. There is no streak decay or gated depth.

## Handoff
- [HANDOFF.md](HANDOFF.md): transitions, API/data contracts, Android responsibilities, integration sequence and acceptance gates.
- [QA.md](QA.md): actual verification and limits.
- `exports/`: screenshots captured by browser verification.
- `app.js`: executable screen/state reference; `style.css`: responsive design tokens.

Native permissions, authentication, alarm scheduling and enforcement are simulations. The demo code is 123456. Seven-day controls preview invitations; no user evidence is fabricated. The Living Orbit treatment remains a reviewable product proposal, not an accepted philosophical claim.

Run `node --check app.js` and `node verify.mjs` from this folder. Browser verification uses the existing repository Playwright dependency.
