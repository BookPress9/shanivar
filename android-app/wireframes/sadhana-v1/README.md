# Shanivar Sadhana — immersive interface study

Interactive founder-review prototype, 12 October 2026. Open [index.html](index.html) directly in a browser. The project is offline and buildless. It stores demo state in browser localStorage and uses only repository-reviewed foundation language plus clearly labelled design proposals.

## Experience thesis

The aura is not a badge layer. It comes from stillness, darkness, bronze light, deliberate motion and language with weight. The central interface is a Living Spine: a seven-centre subtle-body teaching map holding study and practice around a vertical trace. The trace reflects concrete practice activity; chakra illumination is selection and navigation, never diagnosis or a claim that energy was measured. Historical chakra systems vary, and the common contemporary map is not presented as anatomy.

The user’s aura grows through visible ownership: fewer prompts, chosen duration, clear decisions, factual active minutes and practice without the app. Missed days cause no visual damage. No XP, streak loss, rank, public comparison, spiritual title or readiness score exists.

The capability spine is `Arrive → Return → See → Choose → Carry`. These are verbs describing what a person may practise, not ranks describing who they are. Deep study is always open. Practice activity never unlocks intensive methods.

## Included

- Sadhana threshold organized around the Living Spine
- interactive seven-centre study map with explicit tradition/anatomy boundary
- five-part capability path
- practice detail with effort, duration, source and claim boundary
- suitability confirmation and equal external-attention alternative
- immersive Saturn player with pause, End and anchor switching
- completion versus early-ending states and optional honest reflection
- active-minutes/attempt/independent-practice record
- no-player practice route and optional self-report
- named-tradition study lanes and a visible research-only boundary
- new, returning and independently practising review fixtures
